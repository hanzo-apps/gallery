Changelog

What's new in Fernline.

We ship every week. Subscribe in the footer to get these by email.

  1. Oct 7, 2026v3.18New

    Approval policies for MCP tools

    Gate any tool on any MCP server behind a human, with conditions on its arguments. Works with servers you don't control.

    • Policies match tool names with wildcards: github:*, stripe:refund_*
    • Argument conditions use the tool's JSON schema
    • Unverified servers can be blocked until reviewed
  2. Sep 30, 2026v3.17NewImproved

    Edit & approve

    Approvers can now change a tool call's arguments before approving: lower an amount, trim recipients, scope a SQL statement. Edits are schema-validated and land in the audit log.

  3. Sep 23, 2026v3.16New

    Loop guard

    Runs that call the same tool with identical arguments more than N times are stopped and flagged. The default is 20; set it per agent or per tool.

  4. Sep 16, 2026v3.15Improved

    Budget forecasts

    Every budget now shows a month-end forecast from the current run rate, and alerts when the forecast crosses the limit, not just the actual.

  5. Sep 9, 2026v3.14ImprovedFixed

    Faster trace view

    Traces with 2,000+ spans render 6× faster. Fixed collapsed sub-agents re-expanding after selecting a span.

  6. Sep 2, 2026v3.13SecurityNew

    SCIM provisioning

    Provision and deprovision members from your identity provider. Approver roles map from groups.
