What you get

Built for agents, not for API calls.

Nested spans

Sub-agents and parallel tool calls nest under the step that spawned them, so the shape of the run is obvious.

Inputs and outputs

Pretty JSON or rendered markdown for every span, with PII masked by your redaction rules.

Replay

Re-run from any span with a different prompt version, model or tool result, and diff the outcome.

Evals from traces

Save a run as a test case in one click. Score every prompt change against real traffic.

Live tail

Watch runs stream in while you deploy. Filter by agent, status, customer or trigger.

OpenTelemetry native

Bring spans from LangGraph, CrewAI or your own framework through any OTel exporter.
