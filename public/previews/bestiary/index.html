Bestiary · v1.0 · 8 specimens

Interactive point-cloud birds and beasts.

Three birds, a bear, a panther, a wolf, a cobra and a stag, built from geometry and projected by hand onto a 2D canvas. They turn on their own, tilt toward the pointer, and scatter when pressed, then spring back. Zero dependencies, one file, works in any stack.

Usage

Three ways in.

Script tag 
<link rel="stylesheet" href="bestiary.css">
<script src="bestiary.umd.js"></script>

<figure class="sp-plate" data-bestiary="wolf">
  <canvas class="sp-canvas"></canvas>
  <div class="sp-tag">
    <span class="sp-eyebrow">Specimen <span data-sp-index></span></span>
    <span class="sp-tag-value" data-sp-latin></span>
  </div>
  <div class="sp-label"><span class="sp-figure" data-sp-faces></span></div>
</figure>

<script>Bestiary.mount();</script>
ES module 
import { createBestiary } from './bestiary.esm.js';

const beast = createBestiary(canvas, {
  species: 'crane',
  seed: 12,
  spin: 0.0003,
  ink: '#f2f1ee',
});

beast.setSpecies('swallow');
beast.scatter(x, y, 1.5);
beast.destroy();
